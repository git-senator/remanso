# Remanso Concierge — сайт

Сайт консьерж-сервиса в Бразилии: [remansopersona.com](https://remansopersona.com).
Дизайн и вёрстка — мои.

- 4 языка: русский, английский, испанский, португальский (`site/ru`, `site/en`, `site/es`, `site/pt`)
- статический HTML/CSS/JS без фреймворков, плавная прокрутка на Lenis
- адаптивные изображения WebP под разные экраны
- SEO: sitemap, hreflang, разметка Schema.org, Open Graph

Посмотреть локально: открыть `site/index.html` или запустить `npx serve site`.

Телефоны и реквизиты в этой копии заменены заглушками.
